> 学术·理论

## 关于本书

用控制论的语言把有为政府从口号还原为可数学讨论的机制。从1788年瓦特离心调速器讲到通胀目标制，负反馈是全书主角：目标、传感器、执行器与增益构成一切目的性行为的最小结构。逐章讨论增益与时滞的权衡（好心政策为何振荡）、PID的通用控制器逻辑、泰勒规则的反馈设计。附录给出全部推导，作者相信亲手推过的方程才进入直觉。
